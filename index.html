    Data

    Read before you cite

    Reanalysis is model-assisted, records are short, and p-values are unadjusted.

    Methods and limitations

    How to read Sherlock Earth

    What the map shows

    Each colored cell is a 5° grid cell. The color is the slope of a linear regression through the cell's annual values, in the indicator's units per year. The scale is fixed across every view of that indicator, centered on zero: blue means decreasing, red means increasing. Values beyond the legend limits are clipped to the end colors.

    A small white marker with a dark rim means p < 0.05. Cells that are not statistically significant are shown at about 35% opacity. Never judge significance from color alone; read the badge in the details panel.

    Data and processing

    NCEP-DOE Reanalysis 2 is a global model-assisted reanalysis (~1.875° T62 Gaussian grid), not a single-station network. Annual means (and annual totals for precipitation) are calculated from complete calendar years 2014–2025. Country values are area-weighted means of 5° grid cells inside each boundary. City values come from the nearest 5° grid cell, so nearby cities can share a grid cell.

    Country and city data are precomputed in the project JSON. Region values are area-weighted means over each named bounding box. No value is estimated or filled in by this website.

    Statistical caution

    The trend is an ordinary least-squares slope. The p-value tests whether that slope differs from zero; it is not adjusted for multiple testing. With 2,592 cells, roughly 5% (about 130 cells) can appear significant by chance alone. A 10–12 year record is short, and a significant slope is not proof of a long-term climate trend or of causation.

    Fixed color domains

    IndicatorFixed slope limitYears

    Using a separate fixed domain per indicator is deliberate: the units differ, so one shared number would imply a false equivalence. Within an indicator, one color means the same slope everywhere.
